# 🍕 PizzaHub — Backend

**Fresh Pizza. Happy Moments.**

The PizzaHub backend provides the REST APIs and server-side functionality for the pizza ordering and delivery platform. It handles user authentication verification, role-based authorization, pizza menu management, customer orders, vendor operations, and administrative activities. It also manages pizza listing approvals, order status updates, and vendor premium subscriptions.

The backend is built using **Node.js, Express.js, and MongoDB**. Better Auth JWT verification is used to secure API requests and control access based on user roles. Stripe integration handles premium subscription payments and webhook verification, while environment variables are used to manage sensitive configuration securely.
